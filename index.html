Why Today’s Defences Fail

Blocking numbers does not work.

📵 The Old Way

Blocklists and caller ID checks chase phone numbers. But scammers switch to a new number in seconds, so the block never catches up, and the victim answers anyway.

🛡 The ShieldGuard Way

The danger was never the number. It is what is being said. ShieldGuard reads the live conversation, so switching the number changes nothing.

Nobody was analysing the content of the call. Until now.

⏱ 1:05 to 1:30 · 25s
The Solution · Abstract

Meet ShieldGuard.

A secure detector that listens to what is actually said on a call. It turns the call into text, studies the language with a hybrid AI engine, and tells you in plain words why a call is dangerous and what to do next. Protection during the fraud, not after.

Listen

Text, an uploaded recording, or a live capture in the browser, turned into text in an instant.

Analyse

A hybrid engine of machine learning and AI scores the risk and names the scam tactic.

Act

A clear verdict, the exact risky phrases, and safe next steps the user can trust.

Framework · How It Works

A Three Layer Hybrid Engine.

Speech becomes text, then three layers of intelligence work together. Machine learning owns the verdict, and the AI explains it. The AI can never overwrite strong evidence.

Input

Speech to Text

Call audio becomes a clean transcript as it happens.

Whisper
Layer 1 · Learning

Language Model

Reads the wording and owns the numeric risk score.

Calibrated support vector machine
Layer 2 · Memory

Scam Memory

Compares the call against a memory of real scam scripts.

Vector search · ChromaDB
Layer 3 · Review

AI Reviewer

Explains the tactic and recommends safe actions in plain words.

Llama 3.3 70B via Groq
Machine learning stays in charge: when the AI disagrees with strong evidence, the case is flagged “Suspicious, Unconfirmed”, so the model is never silently overwritten.
